ふだん呼んでいる名前で構いません。紹介状の宛名になり、誰が行ったかを見分けるのに使います。来店のあと、しばらくして消します。

紹介状でできること

紹介するあなたに

好きなお店を、自信をもって勧められます。誰の紹介かが相手のお店に伝わるので、紹介した人として覚えてもらいやすくなります。

たとえば、こんな場面で使えます。

  • ラストオーダーのあとに「この先なら、あの店がまだ開いています」と送る
  • 満席でお断りするお客さんに、近くで入れそうなお店を勧める
  • 「ラムが好きなら、あのバーのマスターに聞いてみて」と、好みに合う店を伝える

紹介されたお店に

信頼できるお店や常連からの紹介なので、お店の雰囲気に合うお客さんが来やすくなります。誰の紹介で来たかが分かり、宣伝の費用もかかりません。

たとえば、こんな場面を想定しています。

  • 近くの店のマスターが勧めてくれたお客さんが、そのまま常連になる
  • 初めてのお客さんとも「あのマスターの紹介なんですね」と話が始められる
  • 紹介状で何人来たかを、あとから教えてもらえる

紹介を受け取った人に

初めてのお店でも、「あのお店からの紹介で来ました」と入りやすくなります。

送ったあとの流れ

  1. 宛名を入れてつくると、その人専用の紹介状ができます（30日間有効）。転送されても、使えるのは一度だけです
  2. 受け取った人は、お会計のときかお店を出たあとに、店内のシールを読んで「行ってきました」を押します
  3. お店の手間はシールを置いておくだけで、費用はかかりません
